# Trabalho 2 - Ai - README

## Descrição
Este projeto contém dois scripts principais: `trabalho.py` e `teste csv restaurant.py`. O primeiro script executa o trabalho principal, enquanto o segundo script testa para saber se o CSV esta a funcionar e se encontra no diretorio correto.

## Requisitos
- Python 3.11.9  Windows
- Python 3.9     MacOS


## Execução

### Executar `trabalho.py`
Para executar o script `trabalho.py`, utilize o seguinte comando:

python3 trabalho.py



### Executar `teste csv restaurant.py` com um arquivo CSV
Para testar o script `teste csv restaurant.py` com um arquivo CSV, utilize o seguinte comando:

python3 teste csv restaurant.py
